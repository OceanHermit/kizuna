# 発表スライド

## かさなり（日程調整ツール）— 10分・全16枚

| ファイル | 中身 |
|---|---|
| `kasanari-slides.pptx` | 発表用スライド。各ページに読み上げ台本（ノート）つき |
| `build-kasanari-slides.js` | 上のpptxを組み立てるスクリプト |

構成は「きっかけ → どうやって作ったか → つかいかた → これから」の4章。
ノート欄に各ページの秒数と台詞が入っていて、合計は約10分（610秒）。

デザインは前回の発表資料（「面倒だな」を、形にしています。）と同じ規約で組んである。

- 地の色 `#141210` ／ 朱 `#E8593C` ／ 明るい文字 `#F5F2EC` ／ 弱い文字 `#8A857D`
- 書体は Noto Sans JP、画面は 10 × 5.625 インチ（16:9）
- 左上に朱の小さな四角、右下にノンブル、章扉は朱地

### 直したいとき

```bash
npm install pptxgenjs
node build-kasanari-slides.js kasanari-slides.pptx
```

文字が枠に入りきらない箇所があれば、実行時に警告として出る。
`preview-a.html` / `preview-b.html` も一緒に書き出されるので、
ブラウザで開けば PowerPoint を使わずに全ページの見た目を確認できる。
