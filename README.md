# キズナ ポータル

子どもと保護者のための、キズナクラブのポータルサイトです。

**公開先 → https://oceanhermit.github.io/kizuna/**

## ページ

| URL | 内容 |
|---|---|
| `/` | トップ |
| `/events/` | イベント一覧（これからの予定／終わったイベント） |
| `/events/<slug>/` | イベント詳細。日時・場所・対象・持ちもの・申し込み |
| `/news/` | お知らせ一覧 |
| `/news/<slug>/` | お知らせ詳細 |

## トップページの構成

| # | セクション | 内容 |
|---|---|---|
| — | ヘッダー | ロゴ、メニュー、入会ボタン、ハンバーガー |
| — | ハンバーガーメニュー | 全画面。7項目＋入会・電話ボタン（スマホ・タブレットのみ） |
| 1 | 大きいカラム | 注目イベントのスライド（3件）。矢印・ドット・スワイプで送れ、残り日数を自動表示 |
| 2 | キズナとは | 紹介文と3つの特徴 |
| 3 | 直近のイベント | 3件。2週間以内のものに「もうすぐ」の印 |
| 4 | お知らせ | 新しい順に5件、抜粋つき |
| 5 | キズナ塾 | 申し込みとサポーター募集 |
| 6 | 会員メニュー | プレゼント、ポイント確認、カード、特典、登録変更、会費 |
| 7 | よくある質問 | キャラクターのひとこと＋開閉式・8件 |
| 8 | お問い合わせ | 相談フォーム・電話 |
| — | フッター | サイトマップ |

## デザイン

- **基調**：パステルブルー ＋ ベージュ／**差し色**：ライトグリーン ＋ パープル
- **文字の大小差を約10倍つけている**（一番小さいラベル 11px 〜 連番 106px）。
  のっぺりしないよう、見出し・本文・ラベルの役割をはっきり分けています
- **写真は画面の端まで断ち落とす**。ヒーロー／キズナ塾／お問い合わせは全幅、
  キズナとはの写真は左端まで抜けて、本文が右にずれて重なります
- **角丸は役割を絞った**。ボタン・会員タイル・吹き出しだけに残し、
  写真や一覧は直線と細い罫線で締めています
- セクションに大きな連番（01 / 02 / 03）を置いて、流れをつくっています
- スマホ・タブレット・PC に対応（横スクロールが出ないことを確認済み）

## 写真

仮の写真が9枚入っています（Higgsfield で生成）。**子どもの顔が写らない構図**で
統一しているので、本物の写真に差し替えるときも同じ方針だと見た目が崩れません。

差し替えは `data/photos.json` の `url` を書き換えるだけです。
`assets/img/<キー>.jpg` を置けば、そちらが優先されます（こちらの方が確実です）。

Unsplash の写真も使えます。Unsplash License は商用利用可・許諾不要・
クレジット表記は任意です。写真ページの画像URL（`https://images.unsplash.com/photo-...`）を
`url` に貼ってください。

## 更新のしかた

内容はすべて `data/*.json` に入っています。JSON を直してビルドするだけです。

```bash
python3 build.py        # data/*.json → index.html
```

`index.html` は自動生成されるファイルです。手で編集しないでください。
くわしい運用ルールは [CLAUDE.md](CLAUDE.md) にあります。

## ファイル構成

```
index.html          ← build.py の出力（手で編集しない）
events/             ← 一覧と詳細。ビルドのたびに作り直されます
news/               ← 同上
build.py            ← data/*.json からページ一式を作る
data/
  site.json         連絡先、各リンクのURL、準備中バナー
  hero.json         一番上のスライド（注目イベント・複数可）
  about.json        キズナの紹介と3つの特徴
  events.json       イベントの予定
  news.json         お知らせ
  juku.json         キズナ塾の紹介
  member.json       会員メニューのタイル
  faq.json          よくある質問
  faq_intro.json    質問の上のキャラクターのセリフ
  photos.json       写真・イラストの差し込み口
assets/
  style.css         見た目（色は先頭の :root に集約）
  app.js            メニュー開閉・スライド・残り日数・「もうすぐ」の印だけ（約110行）
```

## 技術的なこと

- 素の HTML / CSS / JavaScript のみ。ビルドツールもフレームワークもありません
- JavaScript が動かなくても、内容はすべて読めます
- `prefers-reduced-motion` に対応しています
- 外部から読み込むのは Google Fonts だけです
