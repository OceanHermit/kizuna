# キズナ サイト リニューアル

現行サイト（kizuna.my.canva.site）を、構造から作り直したトップページです。
最終的に **WordPress のトップページ**として出力することを前提にしています。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | プレビュー用の1枚もの（GitHub Pages でそのまま確認できます） |
| `wordpress/kizuna-top.html` | **WordPress 貼り付け用**。`index.html` から自動生成 |
| `build-wp.py` | `index.html` → `wordpress/kizuna-top.html` の生成スクリプト |
| `assets/` | 写真・QRコードなど画像の置き場（現在は空） |

`index.html` を編集したら `python3 build-wp.py` を実行して WordPress 用を再生成します。

## WordPress への入れ方

1. 固定ページを新規作成（タイトル例：ホーム）
2. **「カスタムHTML」ブロック**を1つ置き、`wordpress/kizuna-top.html` の中身を丸ごと貼り付け
3. 「設定 → 表示設定 → ホームページの表示」で、その固定ページをホームページに指定
4. テーマ側のタイトル表示が二重になる場合は、そのページのみタイトル非表示に設定

- CSS はすべて `.kzn` 配下にスコープ済み。テーマの CSS と衝突しません。
- **JavaScript は不使用**（スマホのメニュー開閉も CSS のみ）。カスタムHTMLブロックで
  スクリプトが除去される環境でも、そのまま動きます。
- フォントは Google Fonts（Zen Maru Gothic / Noto Sans JP）を `@import` で読み込み。

- キズナのコンセプト文（全国の子どもたちが、仏教の教えをもとに、ステキな毎日を…）
- キズナクラブの申し込み／詳細への導線
- キズナ式才能診断（ビッグ5・中学生〜35才・スマホで2分・特典A/B・家族に送る文章の実例）
- キズナ文化祭（9月13日(日) in 東京ビッグサイト）
- キズナポイントプレゼント提供品の受付案内
- キズナコーナーの場所（正本堂2階／サンキュー売店のすぐそば／二千畳行事日のみ）
- 連絡先（070-4171-7569・主催 キズナクラブ・担当 宮部成美・QRコード）

## 作り替えた点

- 情報を **お知らせ / キズナとは / 才能診断 / 文化祭 / キズナコーナー / お問い合わせ** の
  6ブロックに整理し、上から読める順序に
- 「こちら」だらけのリンクを、行き先が分かるボタン・リンク文言に変更
- 画像に焼き込まれていた文字（案内図・見出し）を HTML/CSS で再現し、
  スマホでも拡大せずに読める・検索できる・修正できる状態に
- 桜ピンク＋クリーム＋深緑の配色と丸ゴシックで、やさしい雰囲気を統一
- スマホ用の追従CTA（電話する／申し込む）を追加
