# キズナ サイト リニューアル

現行サイト（kizuna.my.canva.site）を、構造から作り直したトップページです。
最終的に **WordPress のトップページ**として出力することを前提にしています。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | プレビュー用の1枚もの（GitHub Pages でそのまま確認できます） |
| `wordpress/kizuna-top-blocks.html` | **WordPress ブロック版（本命）**。コアブロックのみ・`<style>`不使用 |
| `wordpress/kizuna-top.html` | カスタムHTML版。`index.html` から自動生成（有料プラン向け） |
| `build-wp.py` | `index.html` → `wordpress/kizuna-top.html` の生成スクリプト |
| `assets/` | 写真・QRコードなど画像の置き場（現在は空） |

`index.html` を編集したら `python3 build-wp.py` を実行して WordPress 用を再生成します。

## WordPress への入れ方（ブロック版・推奨）

対象サイト：`kizunaclubsite.wordpress.com`（キズナクラブ）

1. 固定ページを新規作成（タイトル例：ホーム）
2. 右上の「︙」→ **「コードエディター」** に切り替え
3. `wordpress/kizuna-top-blocks.html` の中身を丸ごと貼り付け
4. 「︙」→「ビジュアルエディター」に戻す（普通のブロックとして編集できます）
5. 「設定 → 表示設定 → ホームページの表示」で、その固定ページをホームページに指定
6. 「［画像を入れる］」「写真1〜6」の点線枠を削除し、画像ブロック／ギャラリーブロックを置く

- **`<style>` タグを使っていません。** フリープランでもスタイルが剥がれません
  （色・角丸・余白はすべてブロックのインラインスタイル）
- **JavaScript も不使用**。よくある質問の開閉はコアの「詳細」ブロック
- 使用ブロックはコアのみ：グループ／カラム／見出し／段落／リスト／表／ボタン／詳細
- レスポンシブはブロック側の標準挙動にまかせています（メニュー等は 2列固定）

### 参考：カスタムHTML版

`wordpress/kizuna-top.html` は、`<style>` を含むフル装飾版です。ホバー効果・追従ヘッダー・
細かいレスポンシブ調整が入っていますが、**`<style>` を許可する有料プランが必要**です。
プランを上げた場合はこちらに差し替えると、GitHub Pages のプレビューと同じ見た目になります。
