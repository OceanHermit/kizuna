# キズナ サイト リニューアル

現行サイト（kizuna.my.canva.site）を、構造から作り直したトップページです。
最終的に **無料版 WordPress.com のトップページ**として出力することを前提にしています。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | **デザインの原本（v3）**。GitHub Pages でそのまま確認できます |
| `wordpress/kizuna-top-free.html` | **無料版WordPress用（本命の納品物）** |
| `wordpress/kizuna-event-fallback.html` | イベント欄がはみ出したときの差し替え用 |
| `wordpress/kizuna-top.html` | 有料プラン用。`index.html` をそのまま貼れる版 |
| `build-wp-free.py` | 無料版WordPress用を生成するスクリプト |
| `build-wp.py` | 有料プラン用を生成するスクリプト |
| `assets/` | 本番写真の置き場（現在は空） |

## 無料版 WordPress への入れ方

対象サイト：`kizunaclubsite.wordpress.com`（キズナクラブ）

1. 固定ページを新規作成（タイトル例：ホーム）
2. 右上の「︙」→ **「コードエディター」** に切り替え
3. `wordpress/kizuna-top-free.html` の中身を丸ごと貼り付け
4. 「︙」→「ビジュアルエディター」に戻す
5. 「設定 → 表示設定 → ホームページの表示」でこの固定ページを指定
6. テーマのタイトルが二重に出る場合は、そのページのみタイトル非表示に設定

### 貼ったあとに必ず確認すること

| 見るところ | 正常 | おかしい場合 |
|---|---|---|
| イベント欄 | 横スクロールでカードが送れる | ページ全体が横に動く → `kizuna-event-fallback.html` に差し替え |
| ヒーロー | 写真の上に暗い膜がかかり、白文字が読める | 写真が出ない → 画像URLがブロックされている |
| 見出し | 明朝体で表示される | ゴシックのまま → OS依存。Windowsは游明朝が入っていれば効きます |
| お知らせ欄 | 投稿が並ぶ | 空 → 投稿がまだ無いだけ。投稿を追加すれば自動で並びます |
| 赤い警告 | 出ない | 出たら、その部分を教えてください |

## 設計の考え方（無料版の制約とどう付き合ったか）

無料版 WordPress.com には次の制約があります。

- `<style>` タグは投稿保存時に除去される（カスタムCSSは有料機能）
- インラインスタイルも、WordPress が許可したCSSプロパティしか通らない
  （`animation` / `transform` / `box-shadow` / `transition` は通らない）
- プラグインを入れられない

そこで**ハイブリッド構成**にしています。

| 部分 | 実装 | 理由 |
|---|---|---|
| ヒーロー、イベント、活動、キズナコーナー、お問い合わせ、フッター | **カスタムHTMLブロック** | 見た目を作り込む必要があり、ブロック検証を受けないので確実 |
| セクション見出し、キズナとは、Q&A | **コアブロック** | 文章をそのまま編集できるようにするため |
| お知らせ | **最新の投稿ブロック** | 投稿を追加すれば自動で並ぶ。サムネイル＋抜粋つき |

明朝体は Web フォントを読み込めないため、**OS標準の明朝**
（游明朝／ヒラギノ明朝）を指定しています。欧文は Georgia です。

## v3（原本）から落とした演出

`<style>` が無いと再現できないため、以下は無料版では省いています。

| 落としたもの | 無料版での代替 |
|---|---|
| スクロールに合わせた出現アニメーション | なし（最初から表示） |
| ヒーロー見出しのせり上がり、写真のゆっくりズーム | なし |
| 活動写真の無限マーキー | 6枚の折り返しグリッド |
| ホバー時の拡大・色変化 | なし |
| 追従ヘッダー（スクロールで背景が出る） | テーマ標準のヘッダー |
| スマホ下部の追従CTA | なし（各セクションのボタンで代替） |
| Zen Old Mincho などの Web フォント | OS標準の明朝 |

構成・配色・余白・写真の使い方は、原本とほぼ同じです。

## デザインの方針

参考：[muuuuu.org 教育カテゴリ](https://muuuuu.org/category/industry/education-service) ／
[io3000.com 教育カテゴリ](https://io3000.com/category/bm/education/)

- **写真主役**（現在は picsum.photos のデモ画像）
- **配色**：生成り `#FBF8F3` を地に、深緑 `#14503F` と桜 `#D98C93` を差し色
- **余白**：セクション間 72〜140px、行間 2.0 でゆったり
- **セクション番号**（01 / EVENT / イベント）で全体を通した秩序をつくる

## 画像の差し替え

デモ画像は `https://picsum.photos/seed/xxx/W/H` の形で読み込んでいます。
本番写真は WordPress のメディアにアップし、`src` を差し替えてください。

| 用途 | seed | 推奨サイズ | 枚数 |
|---|---|---|---|
| ヒーロー | `kizuna-hero-2` | 1800×1200 | 1 |
| イベント | `kizuna-ev1`〜`ev6` | 800×600 | 6 |
| キズナとは | `kizuna-ab1` | 900×1120（縦長） | 1 |
| 3つの特徴 | `kizuna-pt1`〜`pt3` | 200×200（丸トリミング） | 3 |
| できること | `kizuna-m1`〜`m6` | 700×880（縦長） | 6 |
| 活動 | `kizuna-a1`〜`a6` | 800×600 | 6 |
| お問い合わせ背景 | `kizuna-ct` | 1600×900 | 1 |

お知らせ欄の画像は、各投稿の**アイキャッチ画像**が自動で使われます。

## もっとデザインを上げたい場合

無料版では上表の演出が落ちます。原本 `index.html` の見た目をそのまま出すには、

1. **WordPress.com を Explorer 以上にする** → `wordpress/kizuna-top.html` を
   カスタムHTMLブロックに貼れば、アニメーションを含めて 100% 再現されます
2. **GitHub Pages で公開する** → 無料。`index.html` がそのまま公開されます
