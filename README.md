# キズナ サイト リニューアル

現行サイト（kizuna.my.canva.site）を、構造から作り直したトップページです。
最終的に **WordPress のトップページ**として出力することを前提にしています。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | **本命のデザイン（v3）**。GitHub Pages でそのまま確認できます |
| `wordpress/kizuna-top-blocks.html` | **WordPress ブロック版（本命）**。コアブロックのみ・`<style>`不使用 |
| `wordpress/kizuna-top.html` | カスタムHTML版。`index.html` から自動生成（有料プラン向け） |
| `build-wp.py` | `index.html` → `wordpress/kizuna-top.html` の生成スクリプト |
| `assets/` | 写真・QRコードなど画像の置き場（現在は空） |

`index.html` を編集したら `python3 build-wp.py` を実行して WordPress 用を再生成します。

## WordPress への入れ方（ブロック版・推奨）

対象サイト：`kizunaclubsite.wordpress.com`（キズナクラブ）

1. 固定ページを新規作成（タイトル例：ホーム）
2. 右上の「︙」→ **「コードエディター」** に切り替え
3. `wordpress/kizuna-top-blocks.html` の中身を丸ごと貼り付け
4. 「︙」→「ビジュアルエディター」に戻す（普通のブロックとして編集できます）
5. 「設定 → 表示設定 → ホームページの表示」で、その固定ページをホームページに指定
6. 「［画像を入れる］」「写真1〜6」の点線枠を削除し、画像ブロック／ギャラリーブロックを置く

- **`<style>` タグを使っていません。** フリープランでもスタイルが剥がれません
  （色・角丸・余白はすべてブロックのインラインスタイル）
- **JavaScript も不使用**。よくある質問の開閉はコアの「詳細」ブロック
- 使用ブロックはコアのみ：グループ／カラム／見出し／段落／リスト／表／ボタン／詳細
- レスポンシブはブロック側の標準挙動にまかせています（メニュー等は 2列固定）

### 参考：カスタムHTML版

`wordpress/kizuna-top.html` は、`<style>` を含むフル装飾版です。ホバー効果・追従ヘッダー・
細かいレスポンシブ調整が入っていますが、**`<style>` を許可する有料プランが必要**です。
プランを上げた場合はこちらに差し替えると、GitHub Pages のプレビューと同じ見た目になります。

## デザインの方針（v3）

参考：[muuuuu.org 教育カテゴリ](https://muuuuu.org/category/industry/education-service) ／
[io3000.com 教育カテゴリ](https://io3000.com/category/bm/education/)

- **写真主役**。全35点（現在は picsum.photos のデモ画像）
- **書体**：見出し = Zen Old Mincho（明朝）／本文 = Zen Kaku Gothic New／欧文 = Cormorant Garamond
- **配色**：生成り `#FBF8F3` を地に、深緑 `#14503F` と桜 `#D98C93` を差し色
- **余白**：セクション間 `clamp(80px,12vw,168px)`、行間 2.0 でゆったり
- **セクション番号**（01 / EVENT / イベント）で全体を通した秩序をつくる
- **動き**：スクロール出現、ヒーロー見出しのスライドイン、写真のズーム、
  活動写真のマーキー。`prefers-reduced-motion` で全て停止
- JavaScript は約40行のみ（出現アニメ・ヘッダー・カルーセル）。切っても内容は全て読めます

## ⚠ WordPress ブロック版について

`wordpress/kizuna-top-blocks.html` は **v2 時点の内容**です。v3 のデザイン
（明朝見出し・横スライド・マーキー・スクロール演出）は `<style>` なしでは再現できないため、
ブロック版には反映していません。v3 を WordPress に載せるには次のいずれかが必要です。

1. **有料プラン（Explorer 以上）にして `wordpress/kizuna-top.html` を貼る** → v3 がそのまま入る
2. **GitHub Pages で公開する** → 無料。デザインは 100% そのまま
3. ブロック版を v3 相当に作り直す → 横スライドとマーキーは再現不可

## ブロック版（v2）で割り切った点

`<style>` が使えない前提のため、カスタムHTML版から以下を落としています。

- 追従ヘッダー・ハンバーガーメニュー（テーマ標準のヘッダーメニューを使ってください）

- ホバー時のアニメーション、ボタンの立体的な影
- メニュータイルの「スマホ2列／PC4列」切り替え（常に2列）
