**28点すべて 1280×1280 の正方形**。9人のキャラクターが、それぞれ3つのポーズで入っています。

元のファイル名は `LINE_ALBUM_2022.11.16_221118_0.jpg` のような連番でした。
`karuta-01` が元の `_0`、`karuta-27` が元の `_26` にあたります。

## 使いかた

**サイトのページに出す**（`build.py` が見るのは `assets/img/` だけなので、こちらに置く）

```
assets/img/faq.png        ← よくある質問のキャラクター（illust.faq）
```

**スプレッドシートの「写真」の欄に貼る**

```
https://oceanhermit.github.io/kizuna/assets/karuta/karuta-01.jpg
```

正方形なので、イベントの小さいサムネイル（`ev2` `ev3`）には合いますが、
全幅で使うヒーローやキズナ塾の帯には横長の写真のほうが向いています。
