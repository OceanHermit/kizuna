### 作らない（外部フォームへのリンクだけ）

入会申し込み／登録内容の変更／相談／キズナ塾サポーター応募

→ `data/site.json` の `links` にURLを入れれば、サイト全体のボタンが一斉に有効になります。

### 統合を検討

- **会員特典** → `/club/` の中の一節で足りるかもしれません
- **キズナカード** → `/point/` に統合できそうです
- **スタッフ・サポーター紹介** → 顔写真と掲載許諾の問題があるため、優先度は低め

## 保留：ポイント確認

**GitHub Pages は静的サイトなので、会員ごとに違う数字を出すことができません。**
ログインして自分のポイントを見る形にするには、次のいずれかが必要です。

| 方法 | 内容 | 向き不向き |
|---|---|---|
| A. 別サービスに作り、リンクする | ポイント確認だけを別のサービス（スプレッドシート＋アプリなど）で作り、このサイトからリンクする | いまの作りを変えずに済む。いちばん現実的 |
| B. ホスティングを変える | Cloudflare Pages など、サーバー側の処理ができる場所へ移す | サイトの作り自体はそのまま移せる。認証と会員データの管理が別途必要 |
| C. 会員管理サービスを使う | 既存の会員管理サービスを導入し、そこへリンクする | 費用がかかるが、会費管理もまとめられる |

**どれを選ぶかで、会員データをどこに置くかが変わります。** 子どもの個人情報を扱うため、
決める前に「何を保存するか」「誰が見られるか」を先に整理することをおすすめします。

## 新しいページの作り方（手順）

1. 必要なら `data/` に JSON を足す
2. `build.py` に `build_xxx()` を書く
3. `build.py` の最後の `made.append(write("xxx", 1, build_xxx))` に1行足す
4. `assets/style.css` に、そのページ用のスタイルを追記する
5. `python3 build.py` → `git add -A && git commit && git push`

くわしくは [CLAUDE.md](../CLAUDE.md) を見てください。
