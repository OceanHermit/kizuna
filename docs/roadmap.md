## 解決：ポイント確認

**すでに動いている仕組みがありました。** Google Apps Script で作られた
「KIZUNAポイント」ページで、カードのQRコードの下の番号を入れると、
その人のポイントが表示されます。会員メニューからリンクしています。

→ 新しく作る必要はありません。ホスティングを変える必要もありません。

ひとつだけ気に留めておくとよい点として、**番号を知っていれば誰でもその人のポイントを見られます**。
子どもの個人情報と結びつく情報をどこまで表示するか、折を見てご確認ください。

## 確認が必要：会費の記述が3か所で食い違っています

| 出典 | 記述 |
|---|---|
| いただいた比較表（最新・採用） | キズナクラブ＝会費なし／個別コース＝中学生まで月200円・高校生以上月500円 |
| 公開中の Canva ページ | ジュニアクラブ（〜小学校低学年）＝無料／キズナクラブ（小学校高学年〜）＝月200円 |
| 旧サイトのよくある質問 | キズナクラブ＝月200円／オンラインコース＝月2000円 |

**比較表を正として `/club/` を作りました。**
よくある質問にあった「オンラインコース（2000円）の精算」の項目は、
金額の裏が取れるまで**いったん外しています**（家庭に誤った金額を出さないため）。

**その後、ポイント申請フォームの説明文に次の記載が見つかり、比較表が裏づけられました。**

> ●キズナクラブ（クラブ費、無料）　登録 200ポイント
> ●キズナクラブ個別コース（クラブ費、月200円／月500円）　登録 500ポイント

→ Canva ページの「キズナクラブ 月200円」は古い記述と判断しました。

**ジュニアクラブは廃止されたとのことで、サイト内の記載をすべて削除しました。**

残る確認事項：
1. オンラインコース月2000円は、いまもありますか？
   いまは「特典②オンラインコース」として会員特典に挙がっています
2. 会員特典③の正式名称（Canva では「教学○○」のままでした）

## 公開を見合わせた情報

会費の納入方法のドキュメントに、払込用紙を依頼する先として
**庶務課の内部メールアドレス**が書かれていました。
公開サイトに載せると検索に拾われ、迷惑メールの対象になりやすいため、
`/club/#fee` では「払込用紙が必要な方は、キズナ担当にご依頼ください」と書き換えています。

そのまま載せたい場合は、お知らせください。

## 新しいページの作り方（手順）

1. 必要なら `data/` に JSON を足す
2. `build.py` に `build_xxx()` を書く
3. `build.py` の最後の `made.append(write("xxx", 1, build_xxx))` に1行足す
4. `assets/style.css` に、そのページ用のスタイルを追記する
5. `python3 build.py` → `git add -A && git commit && git push`

くわしくは [CLAUDE.md](../CLAUDE.md) を見てください。
