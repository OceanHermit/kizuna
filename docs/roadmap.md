このサイトを少しずつ育てていくための計画です。
新しいページを作るときは、まずここを見てください。

最終更新：2026-10-14（リンク一式を登録、/club/ を公開）

---

## 決まっていること

| 項目 | 決定 |
|---|---|
| 入会申込み・登録変更・相談・サポーター応募 | **外部フォームを使う**（サイト内にフォームは作らない） |
| イベント・お知らせの詳細 | **1件ごとにページを作る**（URLを共有できるように） |

### 統合を検討

- **会員特典** → `/club/` の中の一節で足りるかもしれません
- **キズナカード** → `/point/` に統合できそうです
- **スタッフ・サポーター紹介** → 顔写真と掲載許諾の問題があるため、優先度は低め

## 解決：ポイント確認

**すでに動いている仕組みがありました。** Google Apps Script で作られた
「KIZUNAポイント」ページで、カードのQRコードの下の番号を入れると、
その人のポイントが表示されます。会員メニューからリンクしています。

→ 新しく作る必要はありません。ホスティングを変える必要もありません。

ひとつだけ気に留めておくとよい点として、**番号を知っていれば誰でもその人のポイントを見られます**。
子どもの個人情報と結びつく情報をどこまで表示するか、折を見てご確認ください。

## 新しいページの作り方（手順）

1. 必要なら `data/` に JSON を足す
2. `build.py` に `build_xxx()` を書く
3. `build.py` の最後の `made.append(write("xxx", 1, build_xxx))` に1行足す
4. `assets/style.css` に、そのページ用のスタイルを追記する
5. `python3 build.py` → `git add -A && git commit && git push`

くわしくは [CLAUDE.md](../CLAUDE.md) を見てください。
