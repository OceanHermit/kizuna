# スプレッドシートからサイトを更新する仕組み

## 全体の流れ

```
Google スプレッドシート
        │  （リンクを知っている人は閲覧できる設定にして、CSVで読み出す）
        ▼
tools/sync_sheet.py      ← 内容をチェックして data/*.json を書き出す
        ▼
build.py                 ← HTML を書き出す
        ▼
main に push → GitHub Pages で公開
```

動かしているのは `.github/workflows/sync-sheet.yml` です。
30分おきの自動実行と、Actions タブからの手動実行（Run workflow）の2通りで動きます。

## スプレッドシート側

タブは3枚。**タブ名と1行目の見出しは、1文字でも変えると読めなくなります。**

### イベント
`公開` `日付` `時間` `タイトル` `場所` `タグ` `対象` `参加費` `持ちもの`
`申込締切` `申込フォーム` `写真` `一覧に出る文章` `詳細ページの本文` `URL名`

### お知らせ
`公開` `日付` `分類` `タイトル` `一覧に出る文章` `詳細ページの本文` `URL名`

### トップのスライド
`表示` `つなぐイベントのURL名` `タイトル` `日付` `時間` `場所` `文章` `ボタンの文字` `写真`

`つなぐイベントのURL名` を書いて他を空にしておくと、タイトル・日付・時間・場所・文章は
そのイベントからそのまま持ってきます。上書きしたい列だけ書けば大丈夫です。

## 決まりごと

| 列 | 書きかた |
|---|---|
| 公開 / 表示 | `○` が入っている行だけ出ます（`TRUE` `はい` `1` なども可）。空なら出ません |
| 日付・申込締切 | `2026-11-03`。`2026/11/3` でも可。曜日と「あと◯日」は自動計算 |
| 詳細ページの本文 | セル内改行がそのまま段落の区切りになります。空なら「一覧に出る文章」が本文に |
| URL名（slug） | 半角小文字・数字・ハイフンのみ。空なら `event-2026-11-03` のように自動。**公開後は変更しない** |
| 申込フォーム | `site.json` の `links` のキー名（`shindan` `join` など）または URL。空ならボタンなし |
| 写真 | `photos.json` のキー名（`ev1` `ev2` `ev3` / `hero1`〜`hero3`） |

並び順はスプレッドシートの行順ではなく、**イベントは日付の早い順、お知らせは新しい順**に
`sync_sheet.py` が並べ替えます。トップのスライドだけ行順どおりです。

## 入力に問題があったとき

`sync_sheet.py` は **何も書かずに終了コード1で止まります**。サイトは前のままです。
Actions のログに、どの行の何が悪いかが日本語で出ます。止まる条件：

- 日付が読めない
- タイトルが空
- URL名に使えない文字が入っている／他の行と重なっている
- つなぐイベントのURL名が、公開中のイベントに見つからない
- イベントまたはお知らせの公開行が0件（シート名の打ち間違いで全消しになるのを防ぐため）

## 大事な注意

**`data/events.json` `data/news.json` `data/hero.json` の3つは、このワークフローが上書きします。**
手で（または Claude が）直接編集しても、次の同期で消えます。この3つはスプレッドシートが原本です。
それ以外（`about` `faq` `club` `site` `photos` など）はこれまでどおり JSON が原本です。

## 手元での確認

```bash
python3 tools/sync_sheet.py          # 本番のシートから読む
python3 tools/sync_sheet.py --local <CSVの入ったフォルダ>   # テスト用
python3 build.py
```
