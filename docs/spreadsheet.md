# スプレッドシートからサイトを更新する仕組み

## 全体の流れ

```
Google スプレッドシート
   │  ① 文字  … CSV として読む（gviz）
   │  ② 写真  … xlsx として書き出し、セルに貼られた画像を取り出す
   ▼
tools/sync_sheet.py   内容をチェックして data/*.json と assets/img/ を書き出す
   ▼
build.py              HTML を書き出す
   ▼
main に push → GitHub Pages で公開
```

動かしているのは `.github/workflows/sync-sheet.yml` です。
30分おきの自動実行、Actions タブからの手動実行（Run workflow）、
`main` への push の3通りで走ります。

## スプレッドシート側

タブは3枚。**タブ名と1行目の見出しは、1文字でも変えると読めなくなります。**
ただし見出しの `（…）` の中は自由です（`写真（セルに貼る）` は `写真` として読まれます）。

### イベント
`公開` `日付` `時間` `タイトル` `場所` `タグ` `対象` `参加費` `持ちもの`
`申込締切` `申込フォーム` `写真` `一覧に出る文章` `詳細ページの本文`

### お知らせ
`公開` `日付` `分類` `タイトル` `一覧に出る文章` `詳細ページの本文`

### トップのスライド
`表示` `つなぐイベント` `写真` `タイトル` `日付` `時間` `場所` `文章` `ボタンの文字`

`つなぐイベント` には**イベントのタイトル**を入れます（シート側はプルダウン）。
これを選んで他を空にしておくと、タイトル・日付・時間・場所・文章はそのイベントから
引き継がれます。上書きしたい列だけ書けば大丈夫です。

## 決まりごと

| 列 | 書きかた |
|---|---|
| 公開 / 表示 | `○` が入っている行だけ出ます（`TRUE` `はい` `1` なども可）。空なら出ません |
| 日付・申込締切 | `2026-11-03`。`2026/11/3` でも可。曜日と「あと◯日」は自動計算 |
| 詳細ページの本文 | セル内改行がそのまま段落の区切りに。空なら「一覧に出る文章」が本文に |
| 申込フォーム | **フォームのURLをそのまま貼る**。空ならボタンなし。`site.json` の `links` のキー名も一応受け付けます |
| 写真 | **セルに写真を貼る**（挿入 → 画像 → セル内に画像を挿入）。画像のURLも可。空なら既定の写真 |
| 分類 | シート側のプルダウン。文字列としてそのまま使われます |

並び順はシートの行順ではなく、**イベントは日付の早い順、お知らせは新しい順**に
`sync_sheet.py` が並べ替えます。トップのスライドだけ行順どおりです。

### ページのURL（slug）

入力欄はありません。**日付から自動**でつきます。

- イベント → `event-2026-12-13` → `/events/event-2026-12-13/`
- お知らせ → `news-2026-10-10` → `/news/news-2026-10-10/`
- 同じ日に2件以上あるときだけ、タイトルから作った4文字を足します（`news-2026-10-10-7c1d`）

**日付を直すとURLも変わります。** リンクを配ったあとに日付を直すときは注意してください。

### 写真の読み取り

`sync_sheet.py` はシートを xlsx として書き出し、写真の列のセルに貼られた画像を探します。

- 見つかった → `assets/img/ev-<slug>.jpg` / `assets/img/hero1.jpg` などに保存。
  `build.py` は `assets/img/<キー>.*` を `photos.json` より優先するので、そのまま使われます
- 画像のURLが書かれていた → `data/photos.json` に登録します
- 空だった → イベントは並び順で `ev1` `ev2` `ev3` を順番に、スライドは `hero1`〜`hero3` を使います

写真の読み取りに失敗しても**止まりません**。警告を出して、写真は今のままで先に進みます。

## 入力に問題があったとき

`sync_sheet.py` は **何も書かずに終了コード1で止まります**。サイトは前のままです。
Actions のログに、どの行の何が悪いかが日本語で出ます。止まる条件：

- 日付が読めない
- タイトルが空
- 申込フォームがURLでない
- 写真の欄に、画像でもURLでもない文字が入っている
- つなぐイベントが見つからない／同じ名前のイベントが2件以上ある
- イベントまたはお知らせの公開行が0件（シート名の打ち間違いで全消しになるのを防ぐため）

## 大事な注意

**`data/events.json` `data/news.json` `data/hero.json` の3つは、このワークフローが上書きします。**
手で（または Claude が）直接編集しても、次の同期で消えます。この3つはスプレッドシートが原本です。
`data/photos.json` は、写真の列にURLが書かれた分だけ上書きされます（他のキーはそのまま）。
それ以外（`about` `faq` `club` `site` など）はこれまでどおり JSON が原本です。

## 手元での確認

```bash
python3 tools/sync_sheet.py                               # 本番のシートから読む
python3 tools/sync_sheet.py --local <CSVの入ったフォルダ>   # テスト用（写真は読みません）
python3 tools/sheet_images.py <xlsxファイル>               # 写真の取り出しだけ試す
python3 build.py
```
